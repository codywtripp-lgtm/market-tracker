# Site audit, 2026-10-30

Tools: Lighthouse 12.6 (mobile, on the live site), axe-core 4.10 (WCAG 2.0/2.1/2.2 A and AA plus best-practice rules,
10 page types at phone width), a crawl of the built site (titles, descriptions, headings, canonicals, links,
structured data, sitemap), and manual checks against the sources below.

## SEO (Google Search Central)
- Fixed: two near-duplicate pages (/blueberry-prices/new-york/, /grape-prices/new-york/) repeated their item page,
  because those items are only reported in New York. Single-market items no longer get a market sub-page.
- OK: unique titles (none over 65 characters) and descriptions, one h1 a page, canonical on every page, no broken
  internal links, sitemap with real last-modified dates, robots.txt, breadcrumbs markup, valid JSON-LD.
- Known: FAQ rich results no longer show in Google (2023 restriction, now deprecated). The FAQ markup is harmless,
  and Google advised against removing it. The questions stay on the page because they answer real searches.
- Owner actions: check Search Console > Pages for indexing problems; import into Bing Webmaster Tools.

## Performance (web.dev Core Web Vitals)
- Fixed: the typeface loaded from Google Fonts through two extra servers before any text could show. Archivo is now
  served from this site (site/fonts, SIL Open Font License) and preloaded.
- Not fixable on GitHub Pages: files are cached for 10 minutes only (GitHub's setting). It matters little: the
  stylesheet is 8 KB.

## Accessibility (WCAG 2.2 AA)
- Fixed: footer link groups and breadcrumbs had no names for screen readers; month names in the "When to buy"
  calendar were hidden from screen readers on phones; the price history page intro sat outside any landmark.
- Fixed: list links were 20 px tall; now 30 px (WCAG 2.5.8 asks for 24 px).

## Web design and UI
- Done in earlier rounds and checked again: one type scale (6 sizes, 3 weights), light only, no AI-template tells,
  every item row shows the same three lines.
- Fixed: on a phone the first best buy started below the screen; the intro line is shorter, and the first best buy
  now fits on the first screen.

## UX (NN/g heuristics, key tasks)
Tasks walked through: is X cheap this week, find an item in an aisle, understand "usual" and quality, switch to
wholesale, recover from a typo or a dead link.
- OK: search suggests as you type with price and verdict; the empty state suggests examples; the 404 page links to
  both sides; dates are on every page; terms are explained on tap and in "How this works".
- Gap (owner action): no way to contact the site or report a wrong number. Suggest a forwarding address such as
  hello@producepricetracker.com (Porkbun email forwarding is free), linked from the About page and footer. It also
  helps trust signals.
